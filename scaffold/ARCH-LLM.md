# Architecture (agent reference)

Dense agent reference for Typing Program. Confirmed facts only.

# Amphetype Architecture

## Stack

- Python 3.6+ (local dev: 3.11 — see `scaffold/archive/DEPLOY.md`), PyQt5 GUI, SQLite (`statistic`, `text`, `source`, `result`) via `typing_program.Data.DB`.
- **User data (default install):** SQLite file `typing-program.db` under the OS app-data folder for **Typing Program** (macOS: `~/Library/Application Support/Typing Program/`). Dev `--local` / `TYPING_PROGRAM_LOCAL=1`: `typing_program/data/typing-program.db`. Upgrades from Amphetype: on first launch, if the new file is empty and `~/Library/Application Support/amphetype/<user>.db` (or the old username-based name) has data, that file is copied once into the Typing Program folder (`typing_program/legacy_data.py`); the app does not keep reading from `amphetype/` after that. Preferences may override `db_name`.
- Marketing site: static HTML/CSS/JS in `website/`, deployed to Cloudflare Pages (`wrangler.jsonc` → `pages_build_output_dir: ./website`). Checkout URL in `website/checkout.json`; buy buttons open Lemon Squeezy. Post-purchase redirect: `website/thanks.html?order_id=[order_id]` — content shown only after `website/functions/api/verify-order.js` confirms a paid order via Lemon Squeezy API (`LEMONSQUEEZY_API_KEY` secret).
- Sales: Lemon Squeezy ($5 one-time). LS generates license keys per sale. App activates via LS License API on first launch (`typing_program/license.py`); settings keys `license_key`, `license_instance_id`, `license_machine_id`. Offline grace: if a key was activated before and the network is down, launch is allowed.
- Packaging: PyInstaller (`typing_program.spec`, entry `typing_program/main_entry.py`). Ships as a self-contained double-clickable app per OS (macOS `.app`, Windows/Linux one-folder). Because the app resolves files with `Path(__file__).parent / 'data'` and reads `typing_program/VERSION` at import, the spec copies `VERSION` and the whole `data/` tree into `typing_program/` inside the bundle. HTTPS (license activation, Gutenberg import) uses `certifi` CA bundle via `typing_program/https.py`; the spec bundles `certifi`’s `cacert.pem` for frozen builds on all platforms. Build must run on the target OS (PyInstaller does not cross-compile). Build-time deps not in `requirements.txt`: `pyinstaller`, `pillow` (the latter lets PyInstaller convert `typing_program.ico` to the platform icon). Target platforms: Windows, macOS, Linux; v1 ships unsigned (buyers see an OS "unverified developer" warning until code signing is added).
- **In-app updates:** Preferences → General Options → **Check for updates…** (`typing_program/updater.py`, `typing_program/UpdateDialog.py`). Frozen installs only (not dev `--skip-license`). App POSTs stored `license_key` + `license_instance_id` to `POST /api/check-update` (Cloudflare Pages Function); server validates via Lemon Squeezy License API, reads `manifest.json` from R2 bucket `typing-program-updates`, returns signed download URL when a newer `typing_program/VERSION` exists for the OS. Download is verified (SHA-256), extracted, and applied by a detached install script after quit (license data in app-data is untouched). Update artifacts: macOS `Typing Program-mac.zip` (`scripts/mac_app_zip.py`), Windows `Typing Program-win.zip`, Linux `Typing Program-linux.tar.gz`. First purchase still uses Lemon Squeezy email + product files (often `.dmg` on Mac). Publish: `scripts/publish-update.sh`. Env override: `TYPING_PROGRAM_UPDATE_API` (default `https://typing-program.pages.dev/api/check-update`).
- Typing stats: `type` 0 = character, 1 = trigram (3 chars, including spaces/punctuation), 2 = word (`amphetype/typer.py`).
- Main window tabs (`amphetype/Amphetype.py`): Typer, Performance Analysis, Preferences (sub-tabs: General Options, Typer Options, Sources). Window title: **Typing Program That Helps You Type Better**. Last Preferences sub-tab index persists in SQLite (`app_meta.preferences_tab`). General Options shows app version and **Check for updates…** (frozen builds). Lesson Generator (off-tab, for `auto_review`), Database, About/Help, and the old Weakspot tab are not shown; weakspot runs from the Typer tab mode switch.
- **Session clock** (`typing_program/session_timer.py`): top-right corner of the window (`H:MM:SS session`, faint). Counts elapsed time only while the app window is focused and the user has interacted within the last 60 seconds (no clicks/keys for a minute pauses the clock even if the window stays frontmost). Persisted **total practice time** (`app_meta.total_practice_seconds`) sums focused segments across launches (flushed on focus loss and quit). Shown on the Performance Analysis progress card. Toggle via General Options → **Show focused session timer** (`show_session_timer`, default on). Unaffected by lesson pause or tab changes.

## Typing practice (Typer)

- `amphetype/typer.py`: `LessonDocument` (`QTextDocument` subclass), `TyperWidget` (`QTextEdit`), `TyperWindow`. Wired to sources, lesson generator, Weakspot, performance history, and statistics via signals in `amphetype/Amphetype.py`.
- Target text is rendered in the editable document with per-character styling (untyped, correct, error, blocking errors).
- Keystrokes mutate the document in place; timing and statistics via `RunStats` (`amphetype/timingtuple.py`).
- **Pause (ESC)**: during an active lesson (including before the first keystroke), ESC pauses (does not cancel). WPM timing freezes while paused (`RunStats.pause` / `resume`; no timer until typing starts). The lesson canvas greys out with **Continue**, **New**, and **Restart** (stacked); ESC again or **Continue** resumes. Arrow keys cycle the highlighted option (down/right next, up/left previous; wraps); Enter activates the highlighted option. **New** loads another exercise for the current mode (normal / book / weakspot). **Restart** resets the lesson to the beginning. No on-screen ESC hint.
- Supports overwrite/lenient modes, word-aware protected backspacing, progress, and full result recording.
- Footer: faint **improve** / **book** / **corpus** mode toggles (persisted as `practice_mode`: 0 / 1 / 2, default improve); improve mode shows a cyclable submode button (**normal** / **oblivion** / **slowest** / **hesitant** / **damage** — persisted as `typer/improve_submode`); book mode shows chapter progress beside **book** (`Chapter N · done/total`); click **— Title** (bottom right) to switch books. **Read ahead** toggle + level button (`read_ahead_enabled`, `typer/read_ahead_level`: normal / hard / easy — applies in any practice mode); **Block ⌫** toggle (`typer/word_delete_enabled`, default on — after read ahead, before heatmap); novel attribution (`— Title`) in corpus and book modes. Empty states (`lesson_placeholders.py`): corpus/book/improve-normal show a short non-typable message inside the lesson canvas; improve-normal invites corpus/book practice until weakspot targets exist. Clicking **corpus** while already in corpus mode fetches another text (`wantText`).
- **Read ahead** (`amphetype/read_ahead.py`): off by default; when on, level cycles normal (hide current + next word) → hard (+ one more) → easy (current only). Before the lesson starts, full text is shown; the first keystroke applies hiding. Hidden letters use page `background_color` as foreground. Mistyping on a hidden word reveals that word only; other hidden words stay hidden. Compatible with speed heatmap: hidden words stay masked; visible untyped text still gets heatmap colors.
- **Block ⌫** (`typing_program/block_bkspc.py`; pref `typer/word_delete_enabled`): on by default. When on, plain Backspace does nothing; only whole-word backspace works (macOS Option+Backspace, Windows/Linux Ctrl or Alt+Backspace; Cmd/Meta+Backspace also counts). Trains deleting whole words instead of character-mashing. Backspacing does not wipe prior mistakes or first-key timings on those characters (`RunStats.pop_char` only moves the index). End-of-lesson save (`collect_run_stat_rows`): each completed *occurrence* of a word is one sample; samples for the same spelling in that lesson are folded into one `statistic` row with `count` = number of samples (so "the the" → count 2, not two independent double-counts from retypes of one slot).
- Completing a lesson in **corpus** mode advances via `TextManager.nextText`; in **book** mode advances to the next chapter (or chapter part when over `book_max_chars`) via `BookLessonBuilder` (`amphetype/book_mode.py`); in **improve** mode with submode **normal** builds the next weakspot lesson (`WeakSpotLessonBuilder` in `amphetype/WeakSpot.py`); improve submodes **oblivion** / **slowest** / **hesitant** / **damage** auto-pick three slowest **words** (same pools as the former Stats drill buttons) and run as focus drills until the submode is changed or **improve** is clicked.
- **Book mode** loads full book text from `data/texts/<source name>` when present (fuzzy match on ` - <filename>` if needed), else concatenates imported `text` rows in rowid order. Gutenberg wraps are reflowed (`reflow_paragraphs`); formatted chapters are cached in SQLite (`book_chapter_cache`). Each chapter is shown in full (grey inactive before/after); the active slice uses `min_chars`/`max_chars` from Preferences. At each chapter chunk load (and in corpus mode at each text load), the active typing block is vertically centered when a scrollbar is needed. Single newlines (soft wraps) display as line breaks and auto-skip; paragraph breaks (`\n\n`) still use the ⏎ match character (must type Enter) but the glyph is drawn in the page background color so it is invisible (extra newline in the pair auto-skips). Progress per source in `book_progress` (`chapter_index`, `chunk_index`); completed chunks in `book_lesson_done`. Stats recorded per chunk like normal mode.
- Page background uses `typer/background_color` (defaults to Qt window grey); lesson text defaults to light foreground on clear glyph backgrounds (errors still highlighted).
- **Speed heatmap** (off by default): footer **heatmap** click-toggle (white = on, grey = off); when on, one **words** / **trigrams** / **chars** label (click to cycle) plus single-line WPM legend (`<31` purple oblivion, `32–54`, `55–77`, `78–99`, `100+`). Untyped text with stats gets foreground color from `statistic` (all-time query; same counted-row rules as Performance Analysis). Case-sensitive key lookup. Word stats include all lengths (no min length). Trigram mode paints non-overlapping 3-char blocks; contested spans use highest damage (`count·time²·(1+misses/count)`, same as Performance Analysis). Logic: `amphetype/speed_heatmap.py`.
- **Typing sounds** (defaults `type-1` / `error-1`): bundled audio in `data/sounds/` (`type-*`, `error-*` — each dropdown lists only its prefix). Preference **Typer Options → Typing sounds**: `typer/typing_sound`, `typer/typing_error_sound` (`''` = off), `typer/typing_sound_volume` (0–100, default 50), **No sounds** clears both. Playback via `QMediaPlayer`. Peak-normalize bundled files with `python scripts/normalize_typing_sounds.py` (ffmpeg; trims silence tails, 12 ms fade-out, high-pass, target −6 dB peak). Logic: `amphetype/typing_sounds.py`.
- **Word progress feedback** (`amphetype/word_progress.py`): at lesson load, all-time word WPM baselines and raw timing samples are fetched for words in the text. Green highlight, grey `+Nwpm` badges, and end-of-run summary all use the same rule: merging this run's whole-word sample into the historical median pool must raise median WPM by ≥1. After the run: green highlights improved words; orange highlights words with no prior baseline (unique new words in this session); grey boxes show median-shift when &gt;0 (`+Nwpm`, or `+N` on narrow words). Lessons auto-complete trailing whitespace after the last typed letter (book/corpus chunks often end with a word-boundary space). Focus drills save one `<Weakspot>` drill row per target (median timing across reps in that session); counted stats and `result` rows are still skipped. Performance Analysis **words** tab adds an **Improved** column (current all-time median WPM minus median WPM of the first N counted samples, N = word entry floor in `stats_query.py`) only when the word has been typed at least twice; a **most improved** sort option.

### Settings

- Typer options under `typer` and `colors` groups (`amphetype/Config.py`); many general options (font, `auto_review`, `min_*` thresholds, etc.) apply to the typer.

## Performance Analysis tab

- Performance Analysis (`typing_program/PerformanceAnalysis.py`): aggregated keys/trigrams/words from `statistic` with impact/damage ranking (all-time; `ALL_TIME_HIST = 0` in `stats_query.py`). **Words** require at least two counted completions (`WORD_ANALYSIS_MIN_COUNT` in `stats_query.py`); the **don't show count less than** control (`analysis_count`) also clamps to a minimum of 2. Columns: Speed, Hesitation, Count, **Perfect** (mistake-free completions = count − mistakes), Drilled, Impact. Sort includes **lowest perfect %** (`perfect / count`, for finding words worth drilling). **Words** adds an **Improved** column: median WPM in all-time history minus median WPM of the earliest N counted `statistic` rows for that word (N = `analysis_min_count`, same floor as the list), blank when count &lt; N; **most improved** in the sort dropdown (words only). **Progress card** (`typing_program/progress_card.py`) above the list: **WPM since start** (current session WPM minus the first gate-qualifying lesson); **Avg WPM** / **Top X% of adults** (`typing_program/wpm_percentile.py`); **Unique common words typed**; **Total practice time** (persisted focused practice seconds plus the live segment). **Avg WPM** and **WPM since start** stay hidden until `WPM_GATE_MIN_LESSONS` (10) corpus/book/improve-normal `result` rows exist (`stats_query.wpm_gate_complete`); until then the card shows a “complete N lessons” message. Speed is saved on every qualifying lesson from lesson 1; once the gate opens, **Avg WPM** uses all saved runs including the first ten. Refreshes when the tab is selected (`currentChanged`) and after each lesson (`statsChanged`). Every finished lesson in corpus, book, and improve modes stores `char_count` and `duration` on `result` at lesson end (`typingDone` in `typer.py`; book chunks use hash `text_id`s); focus drills do not. Toolbar row: **Show** / **sorted by** / search (substring match via `fetch_analysis_search`; words case-insensitive, keys/trigrams case-sensitive; **Clear** restores the limited list). List capped by `analysis_many` and `analysis_count`. Leaving Performance Analysis clears search.
- **Idle timeout** (`IDLE_THRESHOLD = 2.0` s in `timingtuple.py`): each finished lesson's WPM and `duration` are computed from `RunStats.active_duration()`, which sums inter-keystroke gaps but caps any single gap at the threshold. ESC-pause time is already excluded by `_tnow()`. Stops a distraction mid-lesson (without pressing ESC) from unfairly lowering your recorded speed. Industry standard approach (matches Monkeytype, Keybr).

## Lesson generation (baseline)

- **Lesson Generator** (`amphetype/Lesson.py`) is off-tab (used by `auto_review` only).
- Generator repeats/shuffles list entries and joins with spaces — trigram/key practice produces unreadable strings.
- Novel/text import (`LessonMiner`, `text` table) is separate from stats-based generation.
- **Project Gutenberg US/AUS** (Preferences → Sources): search merged US (`pg_catalog.csv`) + Australia (`GUTINDEX.AUS`) catalogs (stale after 7 days); duplicate titles prefer US. US import uses `pg{id}.txt`; AUS uses PGA URLs (`.txt` or `.html` → text). Boilerplate stripped (`amphetype/gutenberg/strip_headers.py`), saved under `data/texts/`, then `LessonMiner`. Cache: `gutenberg/` under local `data/` or `QStandardPaths` AppLocalData.

## Weakspot intelligent lessons

Auto-build practice text from ranked weak **characters**, **trigrams**, and **words** so the user types real words/phrases, not raw n-grams. Started from Typer tab **improve** mode (`amphetype/WeakSpot.py` builder + `WeakSpotLessons.py`). Submode auto-picks: `amphetype/improve_mode.py`.

### Rules

1. **No bare trigrams or characters** — every line is composed of normal words (letters; capitalization allowed for character practice).
2. **No symbol gibberish** — no random punctuation/symbol runs; lessons need not read like prose but must stay word-like.
3. **Trigram practice** embeds the exact 3-character trigram inside word pairs or phrases (e.g. `e h` → `above home`, `blue horizon`).
4. **Word practice** includes the weak word (e.g. `from` → `from blue horizon`, or combined with a weak trigram → `fly from`).
5. **Character practice** via real words (e.g. weak `C` + weak word `cloth` → `Cloth`).
6. **Multi-target lines** when one phrase covers several weak spots (only when corpus yields a natural match; otherwise combine what fits).
7. **Mix** weak words, trigrams, and characters; prefer stacking targets on the same line when compatible.
8. **Coverage = substring truth**: a target is practiced iff its exact surface appears in the rendered lesson — trigram/char as literal substring (case-sensitive, incl. spaces/punctuation), word as whitespace token (punctuation-stripped, case-insensitive). `covered_targets()` is the single source of truth for building and verifying.
9. **General trigram matching**: any 3-char window. Space pattern — no space → one token (in-word substring, letters+trailing punct like `ol,`/`o,"`, leading punct/hyphen like `-fe`/`"fe`, letter·punct·letter); space at middle → cross-word (left token ends `[0]`, right starts `[2]`, with quote/period surface forms); space at edge → token prefix/suffix with a productive neighbor (` Al`, `At `).
10. **Weak words first**: weak DB words are building blocks; dictionary only completes a boundary slot when no weak word fits. No random filler (see invariant below).
11. **Hyper-compression**: slot fillers also cover other outstanding targets when possible (e.g. `Cool,` covers char `C` + trigram `ol,`).
12. **Selection = importance ("damage")**: `score = time² · (count + misses)` (`time` = median sec/char). Total cost the item imposes: a moderately slow item typed often outranks a very slow item typed once. Slowness is quadratic; frequency is linear and decisive.
13. **Importance-weighted repetition**: each target repeated proportional to score (`allocate_repeats`, every target ≥1, capped); high-impact items get real practice, not a single token.
14. **Cross-lesson freshness**: fresh RNG per build (varied word realizations and order); weighted repetition differs run-to-run; widget passes a 2-lesson recency deque as `recent` keys (weights halved) so emphasis rotates.
15. **No filler invariant**: every emitted phrase covers at least one target (new or repeat); dictionary only completes trigram-boundary slots.
16. **Weakspot drill stats** (`amphetype/stats_query.py`): weakspot runs write `statistic` rows tagged `<Weakspot>` with `count=0` (one row per type target touched per session). They update median time/hesitation for that target but not `sum(count)`, `sum(mistakes)` used for damage. Performance Analysis shows **Perfect** (mistake-free completions = count − mistakes) per target; **Drilled** counts weakspot sessions per target. Lesson Generator / Reviews remain discounted with no writes unless `use_lesson_stats` is on. Heatmap WPM uses the same median-time pool as Analysis (`SPEED_STATS_SQL`); heatmap damage still uses counted rows only.

### Focus drill (Performance Analysis → Typer)

- **Stats** sub-tab: right-click or double-click a row for **Drill** / **Find in corpus** / **Delete from database** (delete removes all `statistic` rows for that target after confirmation). **Find in corpus** (`amphetype/corpus_find.py`, `amphetype/text_index.py`): random matching chunk from imported novels via SQLite FTS5 (`text_fts`, indexed on novel import). Existing DBs: run `python scripts/backfill_corpus_index.py` once manually. Word lookup uses FTS then case-sensitive verify; trigrams/chars scan chunks. On success switches Typer to **corpus** mode; on failure stays on Stats with an inline message (cleared on list refresh, sub-tab change, or leaving Performance Analysis). **Drill** switches to **improve** with a half-length lesson built only from those targets (`build_focus_lesson` in `WeakSpotLessons.py`); focus lessons emit each target word with the exact `data` string from Analysis (no re-capitalization). Finishing replays the same drill; click **improve** in the footer or cycle submode back to **normal** to resume mixed improve lessons. Bulk auto-drills (**oblivion**, **slowest**, **hesitant**, **damage**) live on the Typer footer improve submode cycle, not on Stats buttons. Focus drills write `<Weakspot>` drill rows only (no `result` or counted stats). Word heatmap colors use case-sensitive stat keys; focus-drill targets also use the Analysis WPM captured at drill start.

### Implementation

- Composer: `amphetype/WeakSpotLessons.py` — weak stats drive content; bundled dict (`words-20.txt`) only completes trigram-boundary slots. Tests: `tests/test_weakspot_lessons.py`.
- Widget caches lesson until stats change or user clicks New lesson; preview + Start typing → Typer.
