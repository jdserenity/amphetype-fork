# Typing Program

Typing practice with statistics, novel import, and intelligent weak-spot lessons. Python 3, PyQt5.

## Quick start (dev)

Requires Python 3.11. From repo root:

```sh
./run-dev.sh
# or see docs/DEPLOY.md
```

Launch: `typing-program --skip-license`
